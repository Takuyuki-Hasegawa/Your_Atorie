# YOUR ATORIE の思想

最終更新: 2026-08-27

実装の話ではない。プロダクトが何であり、何を大事にし、何を後回しにするかの正。

画面仕様の詳細は [product-spec.md](./product-spec.md)。

## 一言で

自分の世界観を、消費されない形で、選んだ相手の手に渡す。

## なぜ存在するか

心が動いたこと、面白かった経験、自分にとっての拘りは、いろんな人に共有したい。ただしフィードに流して消費されたくない。ちゃんと受け入れて、聞いてもらいたい。聞くには体力がいる。

人は、信頼している人のことしか知りたいと思わない。人間としてその人が好きでないと、その人が旅で何を感じたか、何に拘っているかは見ない。

だからこれはメディアではない。カードを交換して、相手の世界観を受け取る行為である。note やブログに書かないけれど、友人には渡したいものを、そのために置く。

## 単位は人であり、カードである

コンテンツが先にない。人が先にある。

```
人（アカウント）
  └── その人のカード
        └── 渡される
```

カードは誰かの拘りであり、誰かの手元から出て、誰かの手元に入る。単体でタイムラインに漂わない。アカウントと紐づいて初めて「この人から預かったもの」になる。

作って終わり、公開して終わり、ではない。渡して、受け取られて、初めて成立する。

## 渡すことが本体である

作る画面より、渡す瞬間を大事にする。できればリアルで渡す。画面の向こうに投げるより、その場で手渡す。

渡し方の優先順位:

1. **その場で渡す** — 今はQR。相手がカメラで読む。将来は Bluetooth など、端末を近づけて渡す形を取りたい。ネットで「送った」より、物を渡した感じを残す。
2. **すでに友達の人へ知らせる** — その場にいないが、登録している相手には通知が行き、見られる。信頼の輪の中でのみ。見知らぬ人への配信ではない。

QRは「公開リンクをコピーしてチャットに貼る」ためのものではない。会っている相手に、自分の画面を見せて渡すためのもの。

## 全部、カードである

階層の名前が先にない。カードが先にある。

渡す一枚（タイトル）の中に、カードが並ぶ。そのカードは、それ自体が読むものでも、中にカードを持つ束でもよい。いわゆるトピックは、束になったカードの呼び方にすぎない。

```
渡す一枚（タイトル）
  └── カード … 一枚として読む / 束として開く
        └── カード（束のときだけ。これ以上は入れ子にしない）
```

作成者は「トピックを作るか、カードを作るか」を抽象的に選ぶのではない。並んでいるものに対して、**一枚か、束か** を選ぶ。

- **一枚** — 開いたらそれが本体。写真と一言でも、文章をスクロールして読むのでもよい。「旅で感じたこと」に文書を書いて渡すのは、これ。
- **束** — 中にカードが並ぶ。食・観光が今そうなっている。束の中のカードも、写真ありでも文章だけでもよい。

カードのパターンは種類ではなく、同じものの見え方である。

| パターン | 見え方 |
| --- | --- |
| 写真カード | 流すときはカード型。開くとその一枚。写真は上に全体、文章はすぐ下 |
| 文章カード | 写真なし。羊皮紙に書いて、スクロールして読む |
| 束 | 開くと、中のカードが並ぶ |

### 入れ子は一段まで

カードの中にカードを置ける、という感覚は正しい。ただし無限にネストしない。

リアルで渡すのは一枚である。フォルダの中のフォルダの中のファイル、にはしたくない。束の中は葉（一枚のカード）で止める。退職や起業も、渡す一枚の中に文章カードが並ぶだけ、で足りる。

## いまの試作との対応

実装はまだ「タイトル → トピック → カード」に近い。思想の写像はこう。

- 食 / 観光 / 文化・人 = 束。受け手では手札。手前のカードにタイトルと概要。見えているカードを押すか、ずらして選ぶ
- 旅で感じたこと = 一枚の文章カード（将来、束にして文章カードを並べてもよい）


## 今の一歩

アカウントも友達も Bluetooth も、まだいらない。

```
カードを作る → そのカードのQRを画面に出す
```

受け取った人がQRを開くと、カードが見える。いまはここまで（⑤）。QRの先は②と同じ出力。

ここができないと、人との紐づきも、友達通知も、近づけて渡すことも、全部空転する。

## やらないこと

- 不特定多数向けのフィード、発見、おすすめ、拡散
- 世界観を消費する読み物としてのブログ化
- 説明過多なUI（使い方解説、受け取ってくれてありがとう、など）
- 会っていない他人にカードが届くこと

信頼の外に出さない。聞かれない相手に見せない。
